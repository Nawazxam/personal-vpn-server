# Concepts

Terms worth knowing before (or while) working through this project.

| Term | Meaning |
|---|---|
| **VPN** (Virtual Private Network) | A private, encrypted tunnel between two devices. |
| **Tunnel** | The encrypted "pipe" all traffic travels through. |
| **Encryption** | Scrambling data so nobody in between can read it. |
| **IP Address** | Your device's address on the internet — a VPN hides/changes how this appears to the outside world. |
| **Port Forwarding** | Telling your router "allow outside traffic in through this specific door." |
| **Public vs Private IP** | Private = address inside your home network. Public = the address the internet sees. |
| **NAT** (Network Address Translation) | How a router hides multiple devices behind one public IP. |
| **Handshake** | The process where two devices start a connection and verify each other. |
| **Key Pair** (Public/Private Key) | WireGuard's security basis — two keys that must match to allow a connection, like a password but stronger. |
| **Peer** | Any device connected to the VPN network (phone, laptop, server). |

### Quick self-check before starting hands-on work

- [ ] I know the difference between a VPN and a proxy.
- [ ] I know what encryption means at a basic level.
- [ ] I know the difference between a public IP and a private IP.
- [ ] I know a VPN doesn't change GPS location — only how traffic is routed.
- [ ] I know what a "peer" means in VPN context.

If any of these are a "no," worth a quick refresher before moving to setup.
